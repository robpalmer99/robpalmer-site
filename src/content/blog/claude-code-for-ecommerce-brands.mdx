## Why Claude Code and not a chat window

Claude Code is Anthropic's agent for the terminal, desktop, web and IDE. Anthropic built it for software, and most of the people using it are engineers. Three things about it make it the best creative engine I've used, and none of them has anything to do with code.

**It follows skills.** A skill is a folder with a SKILL.md file inside: a method for one job, written once. Write a Meta ad this way, in this structure, avoiding these words. Review a page against these criteria. Check copy against these platform rules. Install the skill and call it by name. The output stops being the model's taste and starts being yours.

**It reads your files.** Point it at a folder of your reviews, your support tickets, your winning ads and your brand rules and it reads them before it writes. A chat window has to be told everything each time. Claude Code has the research on disk.

**It runs the whole job.** Mine the reviews, cluster the language, rank the angles, write twelve hooks, draft the lander, run the review skill, run the compliance skill, save the files. One instruction, one afternoon, a folder of finished concepts to read. The same skills also work in a Claude.ai project or through the API, so a method you build here travels with you.

If you've written [ChatGPT prompts for copy](/blog/chatgpt-for-copywriting) and been disappointed, this is the difference. Prompts are instructions for one draft. Skills are a method for every draft.

## The four skills to install first

The public skill market is covered in my [roundup of the best Claude Code copywriting skills](/blog/best-claude-code-skills-for-copywriting). For an ecommerce brand these four do most of the work, and all of them are free.

1. **Ad copy, with Meta specs and compliance rules.** Hooks, primary text, headlines and UGC scripts, written to a Schwartz awareness level, with the platform's character limits and the first-person results rule built in. The [ad-copy skill](/blog/claude-code-ad-copy-skill) in my suite does this.
2. **Landing page and pre-sell.** The page each ad sends its traffic to, written to the same angle as the ad so the promise in the hook is the first thing the visitor sees. The [landing-page-copy skill](/blog/claude-code-landing-page-copy-skill).
3. **Copy review.** A copy chief in a file. Grades the draft on big idea, lead, mechanism, offer and close, scores it, names the three fixes that would move conversion most. The [copychief skill](/blog/claude-code-copychief-skill). The review skill is the one that stops the first draft shipping.
4. **Compliance.** A pass against Meta, Google, TikTok and FTC rules with a trigger-word list. The [compliance-checker skill](/blog/claude-code-compliance-checker-skill). In supplements, beauty and anything with a health adjacent claim this is the skill that keeps the ad account.

Add Corey Haines's marketingskills for product and lifecycle pages if your store is SaaS-adjacent in tone, and then build the fifth skill yourself: a brand-voice file made from your ten best-performing pieces of copy. Anthropic's skill-creator will scaffold it in an hour. That fifth skill is the one that makes the other four sound like you.

## The weekly loop

Here's the loop I run for a DTC brand on Meta. It fits in a working week and it's the same loop whether I'm running it or your team is.

**Monday: read the account.** Which hooks won last week, which formats, which audiences. The media buyer pulls the numbers; the strategist reads them for what they say about the next round. One page of notes.

**Tuesday: research and angles.** Claude Code mines the latest reviews, support logs and competitor ads for the customer's own words, clusters them, and ranks angles by awareness level. The strategist picks three to five for the week and writes the one-belief line for each.

**Wednesday: generate.** For each angle, the ad-copy skill writes hooks, primary text and a UGC script; the landing-page skill writes the pre-sell or advertorial; a static-ad brief goes to design. A dozen concepts per angle is normal. The strategist writes the control for the angle most likely to win.

**Thursday: review and check.** The copychief skill grades every draft and the compliance skill flags every risk. The strategist reads what survives, kills most of it, and fixes the rest by hand. Thursday is where the judgement lives, and it's the step brands skip when they let the model ship.

**Friday: ship and brief.** Finished scripts and statics go to the production team with a short handoff note. Landers go to the developer. The media buyer gets the concept list with the hypothesis behind each one, so next Monday's read means something.

Ten to thirty concepts a week, every week, from one strategist, one agent and a production team of two or three. That throughput is what Meta rewards since the Andromeda update, when the system started matching ads to people by reading the creative itself and winning ads began fatiguing in weeks instead of quarters.

## Beyond ads: the rest of the store

Ads are where the leverage is highest, but the same setup runs the rest of an ecommerce brand's copy.

- **Product pages.** The highest-return job after ads, because there are many and the format repeats. Feed the skill the product data and the reviews and write the page as a cold sales page: identification scene, mechanism, proof, objections, offer. Edit the first three by hand and the pattern carries.
- **Email and SMS flows.** Welcome, abandoned cart, post-purchase, win-back, each written to the angle that brought the customer in. The [email funnel](/blog/best-email-copywriters) I wrote for Ben Palmer returns 300 percent on ad spend because every email carries the same argument as the ad.
- **Advertorials and listicles.** The pre-sell formats that make cold traffic work for a product-unaware audience. One skill, one research folder, a new advertorial per angle.
- **Review responses, FAQs, support macros.** Low-stakes, high-volume, and the brand-voice skill keeps them consistent.

The rule across all of it: the agent writes from your research, a skill sets the method, a review skill grades it, and a human decides. Nothing ships that nobody read.

## What it won't do

I'm selling this model, so here's the honest limit.

Claude Code with the best skills in the world does not know which angle to run. It doesn't know that the second-best hook on paper is the one that will survive Meta review and the best one won't. It doesn't know why your control is still beating the challenger that looked better in the review. The agent can't read an ad account and feel which way the market is moving. Those decisions come from campaigns, and no skill file has run one.

That's why the model needs a senior operator at the top. The agent carries the volume. The operator carries the judgement. Brands that get that split right get agency output at a fraction of the cost. Brands that get it wrong get a very fast way to produce copy that doesn't work.
